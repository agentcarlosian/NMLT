# `nmlt-compile`

`nmlt-compile` drives two explicit pre-alpha boundaries. It sends
exact source modules through the lossless surface projection, closed resolver,
bidirectional elaborator, neutral raw-certificate boundary, and independent
kernel. It returns only kernel-issued `CheckedProgram` values.

For the supported finite behavioral profile it also compiles source to
deterministic `behavior-core-v1` JSON containing states, typed terms,
ports, action resource profiles, compositions, wiring, and refinement maps.
That artifact is an inspectable Rust product, not a Lean theorem. Separate Lean
decoding supplies the current semantic authority, and no compiler-correctness
theorem connects the two.

The driver is orchestration, not a second parser or an acceptance authority.
Projection, resolution, elaboration, ordinary-core validation, and behavioral
typing failures retain distinct
stable diagnostic classes. Multi-module callers must provide the complete
closed source set and portable repository-relative paths.
